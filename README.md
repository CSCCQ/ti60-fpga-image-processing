# 基于 Ti60 FPGA 的图像处理与数字识别系统

这是我基于易灵思 Ti60F225 开发的图像处理作品，使用 SC1336 摄像头采集图像，通过 HDMI 输出 1280×720 的画面。工程把滤波、边缘检测、图形识别、数字识别和帧回放放在同一套系统中，使用板上的 K1、K2 两个按键完成操作，固化后可以脱离电脑独立运行。

我在设计中重点考虑了两件事：一是让不同算法的处理结果能够直接观察和比较，二是让识别功能与视频显示同时运行。像素处理由 FPGA 流水线完成，数字分类则由 RV32 SapphireSoC 配合 TinyML 加速器完成。

## 功能演示

长按 K1，画面按下面的顺序循环切换：

**彩色原图 → 中值滤波 → 中值 Sobel → 高斯滤波 → 高斯 Canny → 灰度/二值分屏 → 红边叠加**

两种滤波模式显示处理后的灰度图，便于观察滤波对细节和噪声的影响；两种全屏二值模式分别显示对应的边缘检测结果。分屏模式左右显示摄像头中心的同一区域，左侧为灰度图，右侧为高斯 Canny 二值图。红边模式把检测到的边缘叠加到彩色原图上。

- **数字识别**：在中值 Sobel 或高斯 Canny 模式下长按 K2 开启，再次长按退出。识别印刷数字 0～9，最多显示 16 个数字框，每个框旁标出分类结果，并随目标移动。
- **图形识别**：在红边模式下长按 K2，识别三角形、矩形和圆形。横向识别范围为 100～1180，识别框优先于边缘叠加显示。
- **冻结与回放**：双击 K1 冻结并保存当前帧，再次双击恢复。最多保存 10 帧，存满后覆盖最早的一帧；三击 K1 进入或退出回放。回放时仍能切换显示模式、调整阈值和进行识别，可以用同一张画面对比不同处理结果，也可以翻页查看不同时间保存的画面。
- **阈值与状态显示**：单击 K1、K2 分别增加、降低阈值，每次变化 10。左上角显示 FPS 和 TH，右上角显示当前模式及冻结、回放状态。
- **上电启动**：位流和固件写入 Flash 后，上电即可显示画面并使用全部功能，无需每次下载 ELF。

回放帧保存在 DDR 中，断电后清空。原图、滤波灰度和分屏模式下，长按 K2 不开启识别。

## 实现与测试

边缘处理采用中值滤波＋Sobel、高斯滤波＋Canny 两条通路。我针对低阈值下的闪烁噪点加入了弱边缘确认和邻域筛选，并屏蔽卷积边界产生的四周白线；强光过曝和失焦情况下仍可能有噪点。

数字识别采用 32×32 输入的 INT8 CNN，模型大小为 22,064 字节。在独立的 3,300 张合成测试图上，分类准确率为 99.39%。模型主要面向本工程样张中的印刷数字，实际拍摄效果还受字体、角度、大小和光照影响。

HDMI 输出为 720p、60 Hz，屏幕 FPS 根据显示输出帧计数计算。最终布局布线占用 XLR 60,716/60,800、RAM 256/256、DSP 38/160，时序报告最小 slack 为 0.018 ns。七种模式、识别进出、冻结回放以及断电自动启动均已在板上测试。
