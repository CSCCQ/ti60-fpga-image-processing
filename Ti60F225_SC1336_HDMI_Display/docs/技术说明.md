# 技术说明与指标口径

## 系统结构

SC1336图像经MIPI接收、RAW/Bayer转换、裁剪与DDR缓存进入显示处理流水线。FPGA完成灰度、中值/高斯滤波、Sobel/Canny边缘与图形识别、叠加显示；RV32 SapphireSoC结合TinyML卷积加速器处理数字候选分类。显示链保持固定HDMI同步时序，CPU通过快照和结果寄存器协同，不接管原有相机/HDMI DMA。

双算法共享滑动窗口与缓存。DDR中保留原始帧，冻结保存与回放均能重新应用当前滤波、阈值及识别。多击、长按判定与按键消抖由硬件完成。

## 数字识别

使用指定Calibri Bold印刷数字样式，训练覆盖缩放、轻微旋转/透视、模糊、弯曲和断边等合成变化。包含0–9与非数字拒识类别。

FPGA将二值边缘4×4 OR池化为320×180单比特快照；CPU连通域定位、按比例归一化为32×32输入，执行INT8 CNN后将最多16个框映射回720p坐标。取图与处理重叠，通过精确输入缓存、双向轮廓匹配、有限期标签复用和批量结果发布改善跟随及闪烁。

模型17411参数，TFLite文件22064字节。在独立3300张**合成测试样本**上分类准确率99.39%；这不是相机全场景识别率。主要适用于基本正立、分离、足够大的指定印刷数字；严重模糊、过曝、遮挡、其他字体或6/9大幅翻转需要进一步验证。

## 低阈值降噪

高斯Canny在TH20/30/40时，在高斯前对同一行亮度差≤12的相邻处理值作有界平均，保留两位高斯小数到梯度计算之后。邻域方向与支持度筛选抑制孤立响应；两种全屏二值视图在TH<160时，对弱边缘采用上一帧4×4块占用确认，较强边缘直接通过，显示仍为当前像素。最外侧约8像素的无效卷积边缘被屏蔽。

中值Sobel绕过新增灰度平滑；TH≥50的Canny绕过本次新增平滑/精度处理。红边形状识别通路未加入新增降噪，保留原识别输入。降噪不增加整帧视频缓存延迟，但新出现的弱边缘可能等下一帧确认。过曝与失焦未做专门语义检测，不能保证完全消除噪点。

## 性能与验证

- HDMI：1280×720，60 Hz；FPS读数对应输出视频帧计数，不能作为CNN推理帧率。
- 最终布局布线：XLR 60716/60800，RAM 256/256，DSP 38/160；最终时序报告审计274条路径，最小slack 0.018 ns、负slack路径0。
- 已完成七模式720p整帧及循环切换、回放、数字框标签、按键/FPS/TH、边界和形状通路保持等验证。
- V3对160组合成印刷数字场景进行回归，没有新增正确识别丢失或错误标签；原版与V3均有139组全部识别正确，极端场景仍有原有失败。
- Flash配置写入、主机回读与断电启动通过；用户确认原图颜色和数字识别进入/退出正常。

本次整理不重新修改硬件算法，不重新烧录板卡。原始RTL、固件和最终模型/位流指纹保留；改变的是文件组织、交付文档和构建/部署入口。
