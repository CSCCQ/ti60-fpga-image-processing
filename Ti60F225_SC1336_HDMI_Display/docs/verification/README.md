# 测试记录

这里保存了当前版本的仿真、资源时序、Flash 回读和断电启动记录。`original/` 中保留测试时的原始结果，部分记录仍使用当时的 `sim/...` 或输出目录名，便于对应开发过程。

主要检查内容包括：

1. 七种显示模式的整帧输出和循环切换，以及回放中的模式操作。
2. 数字框与标签、形状通路、按键、FPS 和阈值显示。
3. 弱边缘确认、灰度降噪、画面四边屏蔽，以及数字场景回归。
4. 资源占用和时序，Flash 写入、回读及断电自启动。

打包前还检查了工程、IP、头文件和 ROM 的依赖，并重新编译固件。重新生成的 ELF、BIN、Flash 固件镜像和启动程序与板上运行版本一致。具体结果在 `cleanup_validation.json`，文件 SHA256 清单在 `release/files.sha256.json`。

板上测试记录与合成数据测试分别保留。合成测试集的分类准确率用于衡量模型在这组数据上的表现，实际拍摄还会受到字体、光照、清晰度和目标大小的影响。
