# 交付验证

`original/`保留最终版本的关键验证报告、固化回读及断电启动记录。文件中的 `sim/...`、旧输出目录和源文件路径是**当时执行测试时的溯源记录**，不是本提交包的构建依赖；相应大型测试工作区已归档。

提交时另执行：

1. 当前RTL/固件源码与最终编译指纹一致性检查。
2. Efinity项目、文件清单、IP、头文件、RAM初始化文件依赖检查。
3. FPGA/ELF/TFLite指纹、Flash固件头部、CRC及四个ROM bank校验。
4. 整理后固件重新编译，比较可加载BIN与已验收BIN内容。
5. 所有提交文件SHA256清单校验，RAR完整性与解压内容一致性检查。

重新编译产生的ELF可能由于源码路径调试信息不同而有不同哈希；CPU实际执行内容以BIN一致性检查为准。最终提交的ELF仍使用实板已验收的原文件。
