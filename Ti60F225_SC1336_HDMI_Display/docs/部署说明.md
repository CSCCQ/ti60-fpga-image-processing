# 部署说明

## 文件与地址

| 文件 | 用途 | 地址 |
|---|---|---|
| `release/fpga/Ti60_Demo.bit` | JTAG 临时加载 FPGA 配置 | SRAM |
| `release/fpga/Ti60_Demo.hex` | Flash 配置区 | `0x000000` |
| `release/boot/digits_flash.hex` | 带长度和 CRC 校验头的数字固件 | `0x400000` |
| `release/firmware/evsoc_tinyml_digits.elf` | 手动 JTAG 固件调试/恢复 | 按 ELF 段地址 |

Flash 为8 MiB Winbond W25Q64；配置和固件各使用4 MiB分区。本工程的自动启动过程为 Flash→FPGA配置→片上引导程序→加载校验数字固件→主程序运行。

**两种 HEX 格式不要混用**：`release/fpga/Ti60_Demo.hex` 和 `release/boot/digits_flash.hex` 是 Efinity 每行一个字节的 HEX；`release/firmware/evsoc_tinyml_digits.hex` 是 Intel HEX，不能作为自动启动 Flash 固件直接写入。

## 已固化板卡

连接相机和 HDMI，正常上电即可运行，无需 PC 下载。2026-10-24 已完成 V3 Flash 回读与断电启动验收。

## 临时加载最终版

在工程目录运行：

```powershell
& ./tools/Load-Release.ps1 -CheckOnly
& ./tools/Load-Release.ps1
```

脚本默认 Efinity 路径 `E:/Efinity/2026.1`、RISC-V IDE 路径 `E:/Efinity/efinity-riscv-ide-2026.1`，其他安装位置使用 `-EfinityRoot` 和 `-IdeRoot` 指定。仅写 SRAM，现有 Flash 数字固件应与本版匹配。

## 首次固化或恢复完整镜像

保持供电、JTAG及USB连接稳定，关闭占用下载器的其他程序：

```powershell
& ./tools/Program-Release.ps1 -CheckOnly
& ./tools/Program-Release.ps1
```

此操作默认依次写入固件分区和 FPGA 配置分区，首先备份当前板上全部 Flash 到 `build/deploy/时间戳/`，随后写入并进行主机回读校验。默认1 MHz采用本板已成功的固化参数。**必须看到 `Flash verify successful` 才能视为对应分区校验通过。** 写入期间不要断电。若仅更新配置且板上固件已匹配，可使用 `-Part Configuration`。

通过后断电约5秒再上电，不执行电脑下载，确认原图颜色正常，再检查七种模式、数字识别、形状识别及冻结回放。可执行 `tools/Check-Startup.ps1` 读取固件启动阶段和 CRC；脚本检查后恢复 CPU 运行。

## 手动 ELF 加载

只有调试或恢复需要此流程：先加载匹配 `.bit`，再运行 `tools/Load-DigitsFirmware.ps1`。该脚本临时加载 ELF 并回读，正常上电自动启动不需要它。脚本名中的“Firmware”指处理器程序，TinyML 的 Verilog 参数不能替代这份程序。
