# 第三方组件

本工程是在板级示例和厂商开发工具的基础上扩展的，使用了易灵思官方 IP、SapphireSoC BSP、TinyML 加速器及库、TensorFlow Lite Micro 和相关依赖。

- [Efinix TinyML](https://github.com/Efinix-Inc/tinyml)：加速器、软件库和模型生成工具。
- TensorFlow Lite Micro：应用目录中的 `tensorflow/`，保留随附许可证和源码版权标注。
- 板级示例与视频模块：保留源文件中的原作者和版权说明。
- Calibri：训练使用 Windows 本地字体，仓库中提供训练代码、模型和样张，不附字体文件。

第三方代码按各自原有许可使用。本工程保留了相关版权和作者信息，没有另行更改其授权条款。
