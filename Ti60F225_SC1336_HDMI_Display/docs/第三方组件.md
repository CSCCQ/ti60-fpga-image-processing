# 第三方组件

工程使用易灵思官方IP、SapphireSoC BSP、TinyML加速器及库，TensorFlow Lite Micro与其第三方依赖，以及原板级示例和视频处理模块。各源码中的版权、许可证和原作者标注均保留，适用原有授权条款；本次整理未对第三方代码另行指定开源许可证。

- Efinix TinyML：https://github.com/Efinix-Inc/tinyml
- TensorFlow Lite Micro：应用源码中的 `tensorflow/` 及随附许可证。
- Calibri字体由用户的Windows环境提供，包内只保留训练脚本、模型和样张，不附字体文件。

IP名称中保留的历史命名、运行状态寄存器、板端数字自检和厂商调试接口属于已验收设计的一部分，未通过改名或删减逻辑改变最终位流。
